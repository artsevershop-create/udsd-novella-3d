# 3D-выбор квартир для УДС-Д · ЖК «Новелла»

Коммерческое предложение [3dryad.ru](https://3dryad.ru) для застройщика УДС-Д (Новый Уренгой).

- `index.html` — предложение с калькулятором стоимости и встроенным демо.
- `demo/index.html` — интерактивное 3D-демо: выбор квартиры в квартале, интерьер, вид из окна.
- `CLAUDE.md`, `docs/TZ.md` — контекст и ТЗ для продолжения работы в Claude Code.

Демо-концепт, не официальный сайт застройщика. Планировки, статусы и цены в демо условные.
